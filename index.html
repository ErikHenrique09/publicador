Publicador

Ferramenta pessoal, de um usuário só, que envia ao YouTube os vídeos que o próprio dono do canal revisou e aprovou.

O que faz

  • Envia o vídeo aprovado ao canal do dono como privado, com data e hora para ficar público, título, descrição, tags e thumbnail.
  • Usa a YouTube Data API v3: videos.insert, thumbnails.set e channels.list. Esta última serve só para confirmar em que canal a autorização foi dada.
  • Não lê comentários, inscritos, histórico, e-mail, contatos nem nenhum outro dado da conta.

Quem usa

Só o dono dos canais, nos canais dele. A ferramenta não é oferecida a outras pessoas e não tem cadastro.

English

Publicador is a personal, single-user tool. It uploads to YouTube the videos that the channel owner has reviewed and approved. Each video goes up as private, with a scheduled publish time, title, description, tags and thumbnail.

It uses the YouTube Data API v3: videos.insert, thumbnails.set, and channels.list, which only confirms which channel was authorized. It does not read comments, subscribers, history, email, contacts or any other account data. Only the channel owner uses it, on their own channels. It is not offered to anyone else.
